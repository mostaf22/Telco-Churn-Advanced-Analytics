# 📊 Telco Customer Churn: From Excel Insights to Python Intelligence

## 🎯 Project Overview
This project provides a comprehensive analysis of customer churn for a telecommunications company. It transitions from traditional Excel reporting to an advanced **Python-driven analytical pipeline**, focusing on identifying high-value customers at risk and uncovering technical service issues.

## 🚀 Key Features
* **Automated Data Cleaning:** A robust pipeline that handles missing values, removes duplicates, and standardizes data types.
* **Strategic KPIs:** Calculation of 7 critical business metrics including Churn Rate, Revenue Leakage, and Estimated Customer Lifetime Value (CLV).
* **Interactive Visualizations:** Built with Plotly to uncover deep insights into contract types, monthly charges, and service technology.
* **Business Intelligence:** Focused analysis on the "Fiber Optic Trap" and retention strategies for high-value segments.

## 🔍 Core Insights
1.  **Fiber Optic Issue:** Customers using Fiber Optic services exhibit an **18.42% churn rate**, significantly higher than DSL (6.5%), indicating potential service quality issues.
2.  **Contract Influence:** Month-to-month contracts are the primary drivers of churn. Transitioning customers to 1 or 2-year contracts drastically increases retention.
3.  **High-Value Retention:** The analysis confirms that churners often have higher-than-average monthly bills, leading to disproportionate revenue loss.
